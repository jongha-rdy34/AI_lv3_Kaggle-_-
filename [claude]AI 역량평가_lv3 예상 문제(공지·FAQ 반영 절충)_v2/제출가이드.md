# 제출 가이드 (이 모의의 가정)

FAQ: **"반드시 제출 가이드를 준수하여 제출해주세요. 개인의 부주의로 제출하지 않을 시 0점 처리 됩니다."** 이 모의에서도 형식이 하나라도 틀리면 그 문항은 0점으로 채점합니다(`정답_채점용/score_local.py`). 실제 시험의 제출 대상·방법(Kaggle 업로드, SSAFY GIT 등)은 현장 가이드를 따르세요.

모든 제출 파일은 모의문제 폴더의 `제출물/`에 저장합니다.

## Q3 — `제출물/q3_submission.csv`
| 규칙 | 내용 |
|---|---|
| 열 | 정확히 `id,label` (이 순서, 다른 열 없음 — `to_csv(..., index=False)`) |
| 행 | 600행. **`data/leaf/sample_submission.csv`의 id 순서 그대로** |
| `label` 값 | `healthy`, `rust`, `scab`, `multiple` 중 하나 (소문자, 공백 없음) |
| 빈 값·중복 id | 없음 |

## Q4 — `제출물/q4_submission.csv`
| 규칙 | 내용 |
|---|---|
| 열 | 정확히 `id,grade` |
| 행 | 400행. `data/grade/sample_submission.csv`의 id 순서 그대로 |
| `grade` 값 | **정수** 0~4 (`2.0`처럼 실수로 저장하면 위반) |

## Q5 — `제출물/q5_submission.jsonl`
| 규칙 | 내용 |
|---|---|
| 형식 | JSON Lines: 한 줄에 `{"id": "N041", "record": {...}}` 하나 |
| 줄 | 30줄. `notes.csv`에서 `split == "test"`인 id의 순서 그대로 |
| `record` | 스키마의 8개 키를 모두 가진 객체. 자료형·허용값은 Q5 표를 따름 |

## 확인 방법
- 노트북: `ps.check_submission("q3")` → `[]`(빈 리스트)이면 형식 통과
- 채점(풀이가 끝난 뒤): 모의문제 폴더에서 `python -I 정답_채점용/score_local.py`

## 흔한 0점 원인
- `index=False`를 빼서 `Unnamed: 0` 열이 생김
- 예측을 sample_submission 순서가 아니라 test 이미지 배열 순서로 저장함(`reindex`로 id 기준 정렬 필요)
- 레이블을 정수 인덱스(0~3)로 저장함 / 등급을 실수로 저장함
- 파일 이름 오타(`q3_submision.csv`), 다른 폴더에 저장
- 마지막에 커널을 재시작해 다시 실행하지 않아, 노트북 출력과 제출 파일이 서로 다른 버전임
