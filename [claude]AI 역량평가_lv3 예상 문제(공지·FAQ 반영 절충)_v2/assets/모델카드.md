# 모델 카드: TinyResNet (이 모의의 지정 모델)

| 항목 | 내용 |
|---|---|
| 구조 | ResNet 계열 작은 CNN. 하위 모듈 `conv1 → bn1 → relu → layer1(16ch) → layer2(32ch, /2) → layer3(64ch, /2) → layer4(96ch, /2) → avgpool → fc` |
| 파라미터 수 | 약 22만 개 |
| 사전학습 과제 | 합성 무늬 6종 분류(작은 점, 줄무늬, 체커, 고리, 큰 얼룩, 무늬 없는 타원) 6,000장 |
| 입력 | RGB `(3, 48, 48)`. 학습 때와 같은 크기를 권장합니다 |
| **입력 정규화** | 값을 `[0, 1]`로 바꾼 뒤 채널별 **mean = [0.5, 0.5, 0.5], std = [0.25, 0.25, 0.25]** |
| 출력 | `fc = Linear(96, 6)` (사전학습 과제의 6클래스 logits). 새 과제에서는 교체합니다 |
| 가중치 파일 | `assets/pretrained_tinyresnet.pt` (`state_dict`, CPU) |
| 불러오기 | `ps.load_pretrained_model()` |

**주의:** ImageNet 사전학습 모델의 정규화 값(`mean=[0.485, 0.456, 0.406]`, `std=[0.229, 0.224, 0.225]`)과 다릅니다. 정규화 값은 항상 **그 가중치를 만든 사전학습 조건**을 따릅니다.

출처: Claude가 만든 합성 데이터로 CPU에서 학습한 연습용 가중치입니다(v1 세트와 같은 파일). 잎·등급 데이터는 사전학습에 쓰지 않았습니다. 실제 시험 모델이 아닙니다.
