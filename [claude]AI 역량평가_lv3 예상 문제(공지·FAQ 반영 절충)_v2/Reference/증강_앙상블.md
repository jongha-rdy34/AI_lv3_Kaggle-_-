# 증강 · TTA · 앙상블

## 증강을 고르는 기준
**레이블을 바꾸지 않는 변환만** 씁니다. 그다음 test와 train의 분포 차이(밝기·흐림·방향 등)를 메우는 변환을 우선합니다. 한 번에 하나씩 바꾸고, 고정된 validation으로 비교합니다. 강한 증강이 항상 좋은 것은 아닙니다(과소적합이면 오히려 나빠짐).

| 레이블의 근거 | 안전 | 위험 |
|---|---|---|
| 물체 종류 | 반전, 회전, 작은 크롭, 밝기·대비 | 색조(색이 근거일 때) |
| 개수·크기 | 반전, 90도 회전, 밝기·대비 | 크게 자르기, 확대·축소, MixUp/CutMix |
| 방향·위치 | 밝기·대비 | 반전 |

### `torch.rot90(input, k=1, dims=(0, 1))`
- `dims`의 두 축이 이루는 평면에서 90도씩 `k`번 회전. 이미지 배치 `(B,C,H,W)`는 `dims=(2, 3)`. H≠W이면 모양이 바뀝니다.

### 샘플마다 다른 변환 (배치 텐서)
```python
m = torch.rand(n, generator=g) < 0.5          # 샘플별 선택
xb[m] = xb[m].flip(3)
scale = torch.empty(n, 1, 1, 1).uniform_(lo, hi, generator=g)   # 샘플별 배율 (브로드캐스팅용 모양)
mean = xb.mean(dim=(1, 2, 3), keepdim=True)  # 사진마다 평균 (n,1,1,1)
```
- `keepdim=True`: 집계한 축을 길이 1로 남겨 원래 텐서와 브로드캐스팅됩니다.

### (torchvision) 배치 단위 혼합: `T.MixUp(num_classes)`, `T.CutMix(num_classes)`, `T.RandomChoice([...])`
- `xb, yb = cutmix_or_mixup(xb, yb)` → `yb`가 `(B, C)` soft label. `nn.CrossEntropyLoss`는 soft label을 받습니다. 개수·등급 과제에는 부적합.

## TTA (Test-Time Augmentation)
- 추론 때 원본과 변형본(예: 반전)을 각각 예측해 **평균**. 학습 없이 예측 분산을 줄입니다.
- 분류는 `softmax` 확률을 평균한 뒤 `argmax`, 회귀는 출력값을 평균.
- 레이블을 확실히 바꾸지 않는 변형만 씁니다. 임계값을 쓰는 과제는 **TTA 예측으로 임계값을 다시** 맞춥니다.

## 앙상블
- 모델들이 **서로 다른 실수**를 할수록 이득이 큽니다. 예측 상관(`np.corrcoef(preds)`)이 1에 가까우면 이득이 작습니다.
- 다양성(작음 → 큼): TTA < seed만 다름 < K-fold < 다른 증강·학습 범위·손실 < 다른 구조
- 분류: 확률 평균(soft voting). logits 평균은 모델마다 크기가 달라 한 모델이 좌우할 수 있습니다. 회귀: 출력 평균.
- 가중 평균의 가중치·임계값은 **validation(또는 OOF)으로** 정합니다. test 점수로 정하지 않습니다.

### `sklearn.model_selection.StratifiedKFold(n_splits=5, shuffle=False, random_state=None)`
- `skf.split(X, y)` → `(train_idx, valid_idx)`를 fold 수만큼 생성. 각 fold의 클래스 비율이 전체와 같게 나눕니다. `X`는 길이만 쓰므로 `np.zeros(len(y))`를 넘겨도 됩니다.
- `shuffle=True`일 때만 `random_state`가 의미가 있습니다.

### OOF (out-of-fold) 예측
```python
oof = np.zeros(len(y)); test_preds = []
for tr, va in skf.split(np.zeros(len(y)), y):
    m = train(tr)
    oof[va] = predict(m, va)        # 각 표본을, 그 표본을 학습하지 않은 모델로 예측
    test_preds.append(predict(m, test))
score = metric(y, oof)              # 앙상블 성능의 공정한 추정
test_pred = np.mean(test_preds, axis=0)
```
- 임계값·가중치를 OOF로 맞추면, 작은 validation으로 맞추는 것보다 덜 낙관적입니다.
- 비용: 학습이 fold 수만큼 늘어납니다. 4시간 시험에서는 epoch 수와 fold 수를 시간 예산에 맞춰 정합니다.
