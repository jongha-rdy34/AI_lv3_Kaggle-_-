# 지정 모델과 제공 함수 (`practice_support`, 이 모의 전용)

노트북에서는 `import practice_support as ps`로 씁니다. 시험의 "제공 코드"에 해당합니다.

## 지정 모델
### `ps.load_pretrained_model()` → `TinyResNet`
- 사전학습 가중치(`assets/pretrained_tinyresnet.pt`)를 불러온 CPU 모델. 자세한 내용은 `assets/모델카드.md`.
- 하위 모듈 이름: `conv1, bn1, relu, layer1, layer2, layer3, layer4, avgpool, fc` (torchvision ResNet과 같음)
- `fc`: `Linear(96, 6)` — 사전학습 과제용. 새 과제에 맞게 교체해야 합니다.
- `ps.PRETRAIN_MEAN`, `ps.PRETRAIN_STD`: 모델 카드의 정규화 값(확인용).

## 데이터
- `ps.load_images(folder, split)` → `(ids, images)`; `images`는 `(N, 48, 48, 3)` uint8 RGB
- `ps.csv(folder, name)` → `pd.DataFrame`
- `ps.show_images(images, titles=None, ncols=8)`: 육안 검사용 격자
- `ps.to_float_tensor(images)` → `(N, 3, H, W)` float `[0, 1]`

## Q4 제공 학습기
### `ps.train_regressor(model, x, y, train_idx, scope=("fc",), lr=1e-3, epochs=5, augment=True, batch_size=64, weight_decay=0.0, seed=42, device="cpu")` → model
- `x`: `[0,1]` float `(N,3,H,W)`, `y`: float 등급 `(N,)`, `train_idx`: 학습에 쓸 위치
- `scope`: 학습할 파라미터 이름 접두어. 범위 밖 파라미터는 고정, 범위 밖 BN은 `eval()`
- `augment=True`: 배치마다 좌우·상하 반전 + 밝기 배율 U(0.6, 1.1)
- 정규화(모델 카드 값)는 내부에서 합니다. 손실은 MSE, 옵티마이저는 AdamW.
### `ps.predict_regressor(model, x, batch_size=256, device="cpu")` → numpy `(N,)`

## Q5
### `ps.mock_llm(note_id)` → str
- **모의 응답.** 지정 모델은 이미지 모델이라 채팅이 안 되므로(FAQ), 미리 만든 응답 문자열을 돌려줍니다. 프롬프트 내용과 무관합니다.
### `ps.check_prompt(prompt, note, schema_keys)` → 빠진 요소 리스트 (품질 채점 아님)
### `ps.save_jsonl(records, name)`: `제출물/`에 JSON Lines 저장

## 제출·기타
### `ps.check_submission(kind)` → 문제 목록 (`[]`이면 통과)
- `kind`: `"q3"`, `"q4"`, `"q5"`. `제출가이드.md`의 규칙으로 검사합니다. Kaggle 업로드 때 형식 오류로 거절되는 경우를 미리 잡습니다.
### `ps.SUBMIT`: 제출 폴더 경로(`제출물/`)
### `ps.attempt(name, fn, *args)`: 실행하고, 실패하면 오류만 출력한 뒤 `None` 반환
### `ps.seed_everything(seed=42)`, `with ps.Timer("이름"): ...`
### 진행용 대체물: `ps.ready_clean_leaf()`, `ps.ready_transforms(train)`, `ps.ReadyLeafDataset`, `ps.ready_train_loader(...)`
- 앞 소문항을 못 풀었을 때만 확인 셀이 자동으로 씁니다.
