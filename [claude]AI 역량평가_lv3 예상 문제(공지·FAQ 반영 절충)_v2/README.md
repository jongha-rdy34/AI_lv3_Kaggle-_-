| 공지·FAQ 내용 | 이 세트의 반영 |

## 3. 시작하기 (VSCode)

1. VSCode에서 **이 폴더**를 엽니다(파일 → 폴더 열기).
2. 문제 노트북 하나를 엽니다.
   - `문제_A_빈칸.ipynb`: 핵심 자리만 `___`로 비운 판(Lv2와 비슷). 처음 연습하거나 시간이 부족할 때
   - `문제_B_직접구현.ipynb`: 함수 이름·인자·설명만 있는 판. **실전 연습은 이것으로**
3. 오른쪽 위 **커널 선택**에서 torch가 설치된 Python을 고릅니다.
4. 첫 셀부터 차례로 실행합니다. 막히면 `Reference/00_목차.md`부터 찾아보세요. 인터넷 검색·생성형 AI는 쓰지 않습니다.
5. 끝나면 **커널 재시작 → 모두 실행** 후 저장합니다.
6. 채점: 노트북 마지막 **로컬 채점** 셀을 실행합니다. 문항별 **기존 best → 이번 점수 → 변화**를 표로 보여 주고 `제출물/_score_history.json`에 기록합니다(Kaggle 리더보드 대신). 터미널에서 직접 하려면

```bash
python -I -X utf8 정답_채점용/score_local.py
```

7. `정답_채점용/채점기준.md`의 요구사항 표와 코드 리뷰 체크리스트로 스스로 점검하고, `정답_채점용/정답_해설.ipynb`와 비교합니다.

버전 A는 빈칸을 채우기 전에 실행하면 그 셀에서 `NameError`가 납니다(정상). 버전 B는 빈 상태로도 끝까지 실행되며, 미완성 소문항은 `실패`를 출력하고 진행용 대체물로 넘어갑니다.

## 4. 문항과 시간 (권장 4시간)

| 문항 | 유형 | 소문항 | 시간 |
|---|---|---|---:|
| Q1 데이터 점검 | 구현 | 1-1 구성 요약 · 1-2 깨진/중복 · 1-3 육안·BGR·밝기(+서술) · 1-4 정제 | 35분 |
| Q2 변환·재구성 | 구현 | 2-1 transforms(모델 카드) · 2-2 Dataset · 2-3 층화 분할·균형 샘플러 · 2-4 증강 판단(서술) | 35분 |
| Q3 전이학습 | 구현 + 성능 | 3-1 fc 교체 · 3-2 학습 범위·BN · 3-3 손실 함수 · 3-4 학습 루프(장치) · 3-5 체크포인트 · 3-6 설정 비교 · 3-7 제출 · 3-8 분석 | 60분 |
| Q4 등급 예측 | 성능 | 4-1 회귀 헤드 · 4-2 임계값 · 4-3 그리드 탐색 · 4-4 **baseline 개선** · 4-5 제출 · 4-6 분석 | 50분 |
| Q4 심화 (선택) | 성능 | 4-7 증강 함수·강도 비교 · 4-8 TTA · 4-9 seed 앙상블 · 4-10 K-fold OOF 앙상블·제출 · 4-11 분석 | +30분 |
| Q5 프롬프트 | 구현 + 기준 | 5-1 프롬프트 · 5-2 JSON 스키마 · 5-3 JSON 꺼내기 · 5-4 정규화 · 5-5 자료형 검사·제출 | 50분 |
| 점검·로컬 채점 | | 형식 점검, 커널 재시작 후 전체 실행, 마지막 셀로 **기존 best ↔ 이번 점수** 비교 | 10분 |

CPU 전체 실행 시간은 약 2분, Q4 심화를 포함하면 약 3분입니다(학습 포함). Q4 심화는 4시간 안에 끝내기 빡빡하면 건너뛰는 선택 문항입니다.

## 6. 실제 모델·LLM과 대체물

| 이름 | 정체 |
|---|---|
| `assets/pretrained_tinyresnet.pt` | 합성 무늬 6종으로 사전학습한 작은 ResNet(약 22만 파라미터). torchvision ResNet과 속성 이름이 같아 `resnet18`과 같은 코드로 다룹니다. ImageNet 가중치가 아닙니다 |
| `tv_compat.py` | torchvision이 없는 PC에서만 씁니다. `transforms.v2`의 자주 쓰는 부분과 이름·인자를 맞췄습니다(공식 구현 아님) |
| `ps.mock_llm(note_id)` | **실제 언어모델이 아닙니다.** 미리 만든 응답 문자열이며 프롬프트와 무관합니다 |
| 데이터 | 잎 사진, 등급 사진, 진료 메모 모두 합성 자료입니다. 메모의 인물은 가상입니다 |
