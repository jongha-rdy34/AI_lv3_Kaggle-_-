# [claude] Lv3 모의평가 (공지 반영) v1 — 품질점검 · 증강 · 전이학습 · 등급예측 · JSON추출

**2026-11-04에 받은 Level 3 상세 공지를 반영해 Claude가 만든 창작 모의문제입니다. 공식 문제가 아닙니다.** 공지 요약과 남은 기간 학습 계획은 상위 폴더의 `공지반영_학습계획.md`에 있습니다.

## 1. 공지와 이 세트의 대응

| 공지 분야 | 공지 상세 내용 | 이 세트 | 참고한 샘플 대회 개념 |
|---|---|---|---|
| 데이터 분석/전처리 (이미지 2) | 구성·특성 파악, 품질·분포 점검, 육안 검사 | **Q1** 잎 사진 데이터 점검·정제 | 사과 잎 질병(불균형) |
| | 변환/증강, 학습 데이터 재구성·개선 | **Q2** 텐서 변환·정규화, 증강, 균형 재구성 | 벼 잎 질병(증강) |
| AI 모델링 및 최적화 (이미지 2) | 전이학습·구조 변경, 학습 범위 제어, 손실 함수 구현 | **Q3** `fc` 교체, `requires_grad`·BN 고정, 가중 CE·focal 구현, 불균형 대응 비교 | 사과 잎 질병(불균형) |
| | 하이퍼파라미터 튜닝, 성능 분석·개선안 | **Q4** 회귀 헤드, QWK 구현, 임계값 최적화, 그리드 탐색, 혼동 행렬 분석 | 망막 등급(QWK), 반려동물 사진 점수(이미지 회귀) |
| 프롬프트 엔지니어링 (텍스트 1) | 프롬프트 설계, 정보 정규화·미확정 처리, JSON 스키마·자료형 | **Q5** 가상 진료 메모 → JSON | 의료 메모 정보 구조화 |

공지: 서브 문항을 포함해 총 5문항, 4시간, 요구사항 충족 여부와 풀이 과정을 종합 평가하고, 최종 코드 리뷰를 통과하면 Level 3 등급을 줍니다. 그래서 이 세트는 **점수 순위가 아니라 "요구사항 표 충족 + 읽기 쉬운 코드 + 근거 있는 서술"** 로 스스로 평가하도록 만들었습니다(`정답_채점용/채점기준.md`). 실제 데이터·모델·제출 방식·세부 기준은 미공개이며, Kaggle 페이지는 11/6(금)에 공개됩니다.

## 2. 문항 요약 (권장 4시간, CPU 전체 실행 약 5분)

| 문항 | 소문항 | 핵심 |
|---|---|---|
| Q1 (40분) | 1-1 구성 요약, 1-2 깨진·중복 사진, 1-3 육안 검사·BGR·밝기 분포(+서술), 1-4 정제 | 품질 문제를 **알려 주지 않습니다.** 직접 찾아야 합니다 |
| Q2 (35분) | 2-1 변환·정규화(모델 카드 통계), 2-2 증강(+서술: 왜 색조 변환 금지?), 2-3 층화 분할·균형 재구성 | 레이블을 바꾸지 않는 증강만 쓰기 |
| Q3 (55분) | 3-1 `fc` 교체, 3-2 학습 범위·BN 고정, 3-3 손실 함수 직접 구현, 3-4 학습·예측 함수, 3-5 전략·검증 기준 선택(+서술) | 일반 validation이 test의 밝기 차이를 숨긴다는 점 |
| Q4 (50분) | 4-1 회귀 헤드, 4-2 QWK 구현, 4-3 임계값 최적화, 4-4 그리드 탐색(시간 예산), 4-5 혼동 행렬 분석·개선안(+서술) | 등급 = 회귀 + 임계값 |
| Q5 (50분) | 5-1 프롬프트, 5-2 JSON Schema, 5-3 JSON 꺼내기, 5-4 정규화·미확정 처리, 5-5 자료형 검사·평가 | 모르면 `null`, `bool`은 `int`가 아니다 |

## 3. 실제 모델·LLM과 대체물 구분

| 이름 | 정체 |
|---|---|
| `assets/pretrained_tinyresnet.pt` | Claude가 **합성 무늬 6종**으로 사전학습한 작은 ResNet(파라미터 약 22만 개). torchvision ResNet과 같은 속성 이름(`conv1, bn1, layer1~4, avgpool, fc`)을 써서 실제 `resnet18` 사용법과 같게 연습할 수 있습니다. ImageNet 가중치가 아닙니다. 이 PC에는 torchvision이 없습니다 |
| `ps.mock_llm(note_id)` | **실제 LLM이 아닙니다.** 미리 만든 응답 문자열을 돌려주며 프롬프트 내용과 무관합니다. 실제 LLM에서 흔한 형식 오류를 일부러 섞었습니다 |
| `ps.check_prompt` | 프롬프트에 필수 요소가 들어 있는지만 점검합니다. 품질 채점기가 아닙니다 |
| 데이터 | 잎 사진, 등급 사진, 진료 메모 모두 합성 자료입니다. 메모의 인물은 가상입니다 |

## 5. 실행과 확인

필요 패키지: numpy, pandas, scikit-learn, torch(CPU), matplotlib, jupyter. jsonschema는 있으면 5-2 확인에 씁니다. 이 PC에서 Python 3.12.2, torch 2.5.1+cpu, scikit-learn 1.9.0, matplotlib 3.11.1, jsonschema 4.26.0으로 확인했습니다.

1. 이 폴더에서 JupyterLab을 열고 `Lv3_공지반영_v1_문제.ipynb`를 4시간 타이머로 풉니다.
2. 커널을 재시작하고 전체를 다시 실행해 출력을 저장합니다.
3. 로컬 확인(이 폴더에서):
   ```bash
   python 정답_채점용/score_local.py
   ```
4. `정답_채점용/채점기준.md`의 요구사항 표와 코드 리뷰 체크리스트로 스스로 평가하고, 정답 노트북의 주석과 비교합니다.

규칙: test 정답으로 학습하거나 모델을 고르지 않습니다. 함수 이름·매개변수·반환 형식은 그대로 둡니다. 확인 셀 통과가 요구사항 충족 전부를 뜻하지 않습니다.
