# 정답 예시 실행 검증

- 정답 노트북의 모든 코드 셀을 순서대로 실행했습니다. 문제·정답 노트북은 nbformat 형식을 검사했습니다.
- Q1: 결함 제거 후 508행; 학습/검증 ID가 겹치지 않음을 확인했습니다. Q2: 클래스별 샘플 가중치가 역빈도인지 확인했습니다.
- Q3: 앞쪽 백본 동결과 마지막 블록 학습 설정, 검증 macro-F1 기준 최고 가중치 저장·복원, 제출 ID 정렬을 확인했습니다. 짧은 10 epoch 기준선의 검증 macro-F1은 0.4371입니다. 점수가 낮은 학습용 기준선이므로, 학습률·학습 시간·학습 범위 등을 바꾸어 개선하는 데 사용합니다.
- Q4: 두 동결 설정을 비교하고 선택 모델로 회귀 예측을 만들었습니다. 예시 실행의 검증 RMSE 10.4346, 해당 시점 QWK 0.1749입니다. 두 지표의 최선 epoch가 일치한다고 가정하지 않습니다.
- 모의 test Q3 macro-F1 0.4228; Q4 RMSE 11.8734, QWK 0.1570. 합성 데이터의 모의 점수이며 실제 시험 성적·목표 기준이 아닙니다.
- Q5: 수작업 예시 2개를 예시 정답과 비교하고 스키마를 검증했습니다. 잘못된 자료형과 중복 제출 ID가 거부되는지 확인했습니다. 실제 언어모델은 실행하지 않았습니다.
- 모델 학습 결과는 seed·라이브러리·장치에 따라 달라질 수 있습니다. Q1·Q2의 풀이 과정과 Q5의 프롬프트 충실도는 로컬 점수만으로 평가할 수 없습니다.
