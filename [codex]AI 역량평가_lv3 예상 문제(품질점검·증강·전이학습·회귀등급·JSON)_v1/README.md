# Level 3 상세 공지 반영 모의평가 — 5문항

**창작 연습문제입니다.** 11/4 공지에 확인된 ‘이미지 데이터 분석/전처리 2문항, 이미지 모델링/최적화 2문항, 프롬프트 엔지니어링 1문항’과 4시간 및 풀이·코드 리뷰를 반영했습니다. 세부 주제, 데이터, 모델, 배점, 지표, 제출 형식과 허용 라이브러리는 확인되지 않아 본 세트의 설정은 모두 연습용 가정입니다.

## 시작

1. `Lv3_공지반영_문제.ipynb`를 이 폴더에서 Jupyter로 열어 풉니다. 문제 본문과 TODO가 있습니다.
2. `정답_채점용/Lv3_공지반영_정답해설.ipynb`은 별도 예시 답안입니다. 풀이 전 열지 마세요. 코드의 한국어 주석은 각 단계의 목적·입력 형태·주의점을 설명합니다.
3. `Reference.md`에는 문제에서 제공한다고 가정한 핵심 API가 있습니다. `practice_support.py`, `data/`, `assets/`는 제공 자료입니다.
4. 예측과 모델 파일은 `제출물/`에 생성합니다. 모의 종료 후 `정답_채점용/로컬채점.py`를 실행할 수 있습니다. 정답은 같은 PC에 있으므로 실제 비공개 평가 환경이 아닙니다.

## 문항 구성과 240분 예시

| 문항 | 연습 과제 | 예시 시간 |
|---|---|---:|
| 1 | 이미지 수량·품질·분포·육안 검사, train/validation 분리 | 40분 |
| 2 | 이미지 Dataset, 안전한 증강, 불균형 샘플링과 데이터 누출 방지 | 40분 |
| 3 | 사전학습 백본의 전이학습, 동결 제어, 분류 손실, 최선 모델 저장 | 60분 |
| 4 | 이미지 회귀 학습·RMSE·등급 QWK, 실험 비교와 개선 근거 | 55분 |
| 5 | 미확정값 및 단위 정규화를 포함한 구조화 JSON 프롬프트 | 30분 |
| 제출·코드 리뷰 대비 | 실행 결과와 제출물 확인 | 15분 |

실제 공지는 서브문항 포함 총 5문항이나, 본 세트는 5개 항목으로 연습하며 각 항목의 글머리표는 독립 채점 문항이 아니라 요구조건입니다. 상세 구성은 창작 연습용입니다. 실제 문제의 세부 구성과 같다고 보장하지 않습니다. 이전 문항 미완성 시 `ready_splits.csv`와 제공 Dataset으로 다음 문항을 독립 진행할 수 있습니다.

Q3·Q4의 데이터는 이전 프로젝트에서 만든 **합성 도형**이며 백본은 해당 모의문제에서 별도의 합성 도형으로 사전학습한 작은 CNN입니다. 실제 의료/식물/동물 사진이나 실제 시험 모델이 아닙니다. Q4의 연속형 점수도 합성이며 의료 진단에 쓰지 않습니다.

Q5는 실제 언어모델을 포함하지 않습니다. 학습자는 프롬프트를 직접 작성하고 예상 결과를 확인합니다. 제공 검증기는 JSON 문법·스키마만 검사하며 의미 충실도를 보장하지 않습니다. 실제 LLM 실행 및 정확도는 이 세트에서 검증하지 않습니다.

필수 패키지: Python, numpy, pandas, scikit-learn, matplotlib, torch, jupyter/nbformat. 인터넷 접속이나 추가 모델 다운로드 없이 연습합니다.
