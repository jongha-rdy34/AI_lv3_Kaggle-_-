## 6. Lv2 복습점과 이 세트의 연결

Lv2 제출본의 자체 예상 채점은 94/100이며 공식 점수가 아닙니다. 그때 확인한 복습점을 다음 소문항에 넣었습니다.

| Lv2 복습점 | 연습 소문항 | 확인 셀이 잡는 실수 |
|---|---|---|
| 8(a) 내적만 쓰고 노름으로 나누지 않음 | 2-3, 2-5 | 벡터 크기를 3.7배로 바꾸면 값이 달라짐, 영벡터에서 NaN |
| 8(b) `range(8)` 고정 → 입력 개수가 바뀌면 오류·누락 | 2-4 `top_k_indices`, 3-5 배치 추론, 1-5 | 개수 < k, N이 batch_size로 안 나누어떨어짐, 크기 1 입력 |
| 입력 크기가 바뀌어도 동작하는 코드 | 3-2 | 24·32·48 크기 입력 모두 `(B,4)` |
| 7번 `idxmin`+`iloc` 혼용 | 1-4, 1-5, 2-1, 2-6 | 위치가 아닌 **id·이름**으로 맞추기 (sample 순서 ≠ test 순서) |
| Q5 일부 파라미터만 학습 | 3-3, 3-4 | 학습 파라미터 개수 260 / 37,188 |

백지 코드 연습 목록 (Reference를 보지 않고):
1. `cosine_similarity_matrix(A, B)` — 1차원·2차원 입력, 영벡터
2. `top_k_indices(scores, k)` — 길이가 k보다 짧을 때
3. id 기준 정렬: `Series.map` / `reindex` / dict 위치표
4. `ColumnTransformer`(중앙값+표준화 / 최빈값+원-핫 `handle_unknown="ignore"`) + K-fold 루프
5. `AdaptiveAvgPool2d(1)` 헤드 + `requires_grad` 고정·해제 + 학습 파라미터만 optimizer에 넘기기
6. `train_one_epoch` / `evaluate`(`model.eval()` + `torch.no_grad()`) / 배치 추론
