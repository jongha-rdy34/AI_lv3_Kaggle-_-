# 검증 결과 (2026-11-02)

환경: Windows 10, Python 3.12.2, numpy 2.5.2, pandas 3.0.5, scikit-learn 1.9.0, torch 2.5.1+cpu. 네트워크·GPU 미사용.

## 실행 확인

- `Lv3_모의_v1_정답.ipynb`: nbconvert로 처음부터 끝까지 실행했습니다. 오류나 진행용 대체 입력 사용 없이 끝났고 약 1분 40초 걸렸습니다. 출력은 노트북에 저장되어 있습니다.
- `Lv3_모의_v1_문제.ipynb`(빈칸 상태): 끝까지 실행되며 각 소문항은 `[x-y] 실패`를 출력하고 진행용 입력으로 다음 셀을 이어 갑니다. 문제 파일에는 출력을 저장하지 않았습니다.
- 정답 제출물은 `정답_제출예시/`로 옮겼습니다. 모의문제 루트의 `제출물/`은 비어 있는 상태(폴더 없음)에서 시작합니다.

## test 지표 (정답 노트북 기준과 다른 방법 비교)

| 문항 | 방법 | validation | test |
|---|---|---|---|
| Q1 RMSE↓ | 평균값 예측 | 12.89 (std) | 12.48 |
| | **Ridge (정답 선택)** | CV 7.45 | **6.42** |
| | HistGradientBoosting | CV 7.92 | 6.96 |
| | Ridge, 시간 특징 없이 | — | 7.63 |
| Q2 macro-F1↑ | TF-IDF char_wb(2,4) + LR | 0.996 | **0.732** |
| | **코사인 kNN k=5 (정답 선택)** | 0.996 | **0.983** |
| | 코사인 kNN k=15 | 1.000 | 0.984 |
| | 프로토타입 | 1.000 | 0.983 |
| | 노름 없이 내적 kNN k=5 (Lv2 8(a) 실수 재현) | — | 0.977 |
| Q3 accuracy↑ | head만 16 epoch | 0.762 | 0.790 |
| | **head 8 + block4 8 (정답 셀)** | 0.796 | **0.821** |
| | 사전학습 백본 전체 미세조정 16 epoch | 0.917 | 0.931 |
| | 백본 없이 처음부터 16 epoch | 0.387 | 0.344 |

해석:
- Q1: 생성 규칙이 거의 선형이라 Ridge가 더 낫습니다. 복잡한 모델이 항상 이기지 않으므로 CV로 고릅니다. 사고 지연 이상치(약 0.8%)가 RMSE를 키워 fold 점수가 5.8~9.2로 흔들립니다.
- Q2: validation(train과 같은 분포)으로는 세 방법을 구분할 수 없습니다. test에는 처음 보는 어절이 22% 있어 TF-IDF만 크게 떨어집니다. 그래서 2-6 서술에서 **분포 점검**을 근거로 쓰는 것이 핵심입니다. 노름 없는 내적도 이 데이터에서는 점수가 크게 떨어지지 않습니다. Lv2에서 top-3가 같게 나왔던 것과 같은 현상이며, 이런 실수는 지표가 아니라 **확인 셀(배율 불변 검사)과 과정 채점**에서 드러납니다.
- Q3: 정답 셀은 시간을 줄이려고 일부만 학습했습니다. 시간이 남으면 전체 미세조정(낮은 학습률)으로 0.93까지 올릴 수 있으며, 이는 지표 개선용 추가 연습입니다. 처음부터 학습하면 같은 epoch 안에 거의 학습되지 않아 사전학습 백본의 효과가 드러납니다.

## 과정 채점 기준 (가정, 100점)

| 소문항 | 점 | 만점 조건 | 자주 하는 실수(감점 예) |
|---|---:|---|---|
| 1-1 | 5 | 네 열 정확, 입력 df 불변, 0/1 정수 | `df["hour"]=...`로 원본 수정, bool 그대로 |
| 1-2 | 8 | 수치 중앙값+표준화, 범주 최빈값+원-핫 ignore | `handle_unknown` 누락 → test의 `은평`에서 오류 |
| 1-3 | 10 (서술 2) | fold마다 새 Pipeline을 학습 fold에만 fit, RMSE 정확 | 전체 X에 전처리를 먼저 fit(누수), `loc`/`iloc` 혼동, MSE 반환 |
| 1-4 | 7 | CV 평균 최소 선택, 전체 train 재학습, 0 미만 자르기 | test 정답으로 선택, 마지막 fold 모델 재사용 |
| 1-5 | 5 | id 기준 정렬 | `sub["delivery_min"]=pred` 위치 대입(sample 순서 ≠ test 순서) |
| 2-1 | 5 | id→위치 매핑, 없는 id에 KeyError | 캐시 순서를 그대로 사용 |
| 2-2 | 6 | 지정 파이프라인, macro F1 | `average="micro"`/accuracy |
| 2-3 | 8 | 행별 노름으로 나눔, 1차원 입력, 영벡터 0 | **내적만 계산**(Lv2 8(a)), `axis` 실수, 전체 노름 하나로 나눔 |
| 2-4 | 8 | 내림차순 top-k, k>길이 처리, 유사도 합 투표 | 오름차순, `range(5)` 고정, 단순 다수결(부분 감점) |
| 2-5 | 5 | 정규화 후 클래스 평균, 코사인 argmax | 정규화 없이 평균 |
| 2-6 | 3 | 분포 변화 근거로 임베딩 방식 선택 | validation 점수만 보고 tfidf 선택(근거가 타당하면 부분 점수) |
| 3-1 | 6 | (N,3,H,W) float [0,1], 채널 통계 (3,), 브로드캐스팅 | `reshape`로 축 변경(픽셀 섞임), 전체 스칼라 평균 |
| 3-2 | 7 | AdaptiveAvgPool + Linear(out_channels) | `Linear(64*4*4, …)` 하드코딩 → 48 입력 실패 |
| 3-3 | 5 | 백본 고정·지정 블록 해제·head 학습, 리스트 반환 | head까지 고정, 반환에 고정 파라미터 포함 |
| 3-4 | 8 | train/eval 전환, zero_grad→backward→step, 가중 평균, no_grad | `zero_grad` 누락, eval 모드 미전환, 배치 평균의 평균 |
| 3-5 | 4 | 마지막 짧은 배치 포함, eval+no_grad | `range(N // batch_size)`로 마지막 배치 누락 |
