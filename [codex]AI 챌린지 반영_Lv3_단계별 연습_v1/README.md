## AI 챌린지에서 무엇을 반영했나요?

사용자가 제공한 `(260908)_baseline_colab.ipynb`의 ‘설정 → CSV/이미지 읽기 → 모델 → Dataset/DataLoader → 학습/검증 → 추론 → CSV’ 흐름과 많은 코드를 제공하는 방식을 참고했습니다. 해당 원본은 Qwen2.5-VL-3B, 양자화·LoRA·GPU·다운로드를 이용하는 VQA 코드입니다.

이번 연습은 **CPU에서 실행할 수 있는 작은 CNN**으로 바꾸고, 최신 Level 3 공지에 맞춰 이미지 품질/분포, 변환/증강, 전이학습 분류, 이미지 회귀·등급, JSON 프롬프트의 5개 과제로 구성했습니다. Qwen/LoRA/AMP/gradient accumulation은 이 입문 세트의 구현 대상이 아닙니다. 이것이 시험에서 제외된다는 뜻은 아닙니다.

## 연습 데이터는 어디서 왔나요?

- **실제 AI 챌린지 사진이 아닙니다.** 현재 프로젝트의 이전 모의문제에서 생성한 원·사각형·삼각형·십자 합성 도형 이미지입니다. 실제 질병·의료·동물 사진이 아닙니다. 인터넷에서 내려받지 않습니다.
- 학습 이미지 510장 중 검은 이미지 2장을 제외하면 유효 이미지 508장이고, 메타데이터 결함을 추가한 CSV가 513행입니다. test 160장은 학습 ID와 분리되어 있습니다.
- `images/train`, `images/test`: 눈으로 열 수 있는 PNG. `data/train.csv`, `data/test.csv`: 이미지 경로를 포함한 CSV. PNG의 픽셀은 원래 NPZ와 동일합니다. 제공된 로더는 속도를 위해 NPZ 배열을 사용할 수도 있고, Q2 Dataset은 PNG를 직접 읽습니다.
- score는 이미지에서 만든 합성 0~100 값입니다. 실제 인기 점수나 질병 심각도가 아닙니다. `assets/pretrained_backbone.pt`는 이전 모의문제에서 다른 합성 도형으로 사전학습한 백본입니다. `assets/SOURCE.md`를 참고하세요.
- JSON 문항은 가상의 고객 문의와 수작업 예상 결과를 사용합니다. 실제 LLM이나 가짜 LLM 출력을 쓰지 않습니다.
