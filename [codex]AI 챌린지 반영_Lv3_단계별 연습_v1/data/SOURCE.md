# 연습 데이터 출처

이 세트의 사진은 실제 AI 챌린지 사진이 아닙니다. 기존 프로젝트의 `[claude]AI 역량평가_lv3 예상 문제(회귀·텍스트 분류·이미지 분류)_v1`에서 생성한 합성 도형을 이전 공지 반영 Codex 세트가 정제·구성했고, 이번 세트는 그 510장 train / 160장 test 배열을 재사용했습니다. PNG 파일은 그 배열을 RGB로 그대로 저장한 것입니다. test 정답은 학습 입력에서 분리했습니다.

노트북은 `data/train.csv`, `data/test.csv`와 PNG 경로를 사용합니다. `train_metadata.csv`는 이전 세트와의 호환용 동일 메타데이터 사본으로, 직접 변경하지 않아도 됩니다. score는 이미지의 색 특성으로 만든 합성값입니다. 모델은 다른 합성 도형으로 사전학습한 소형 CNN이며 실제 챌린지의 Qwen 모델이 아닙니다.

원본 AI 챌린지 노트북은 코드 흐름과 코드 제공 방식을 참고한 자료이며 실행·다운로드하거나 변경하지 않았습니다.
